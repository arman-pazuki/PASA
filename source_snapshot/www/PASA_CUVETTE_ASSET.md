# Sample-color bench asset

Created 2026-09-11 using the built-in ImageGen tool. The existing PASA welcome
image was a style reference. The original output is `pasa-cuvette-bench.png`.
The scene contains an empty bench and lamp: no generated sample values or
cuvettes are included in the image.

The approved refinement is `pasa-cuvette-photo.png`, generated by ImageGen from
the empty bench and the welcome image. It adds one photographic cuvette with
colorless liquid, realistic glass walls, a meniscus, rim, base, and reflections.
`pasa-cuvette-photo.rds` is the local raster cache used by R's built-in grid
graphics. It includes the neutral scene and the photographic glass on a soft
plotting mask for arranging several samples on a continuous bench. The original
PNG remains unchanged. The earlier empty-bench PNG/RDS are retained as source
assets and provenance for that background.

No extra R image package or network access is needed at runtime. Each row has
one lamp at the left. `pasa_cuvettes.R` draws the spectrum-derived color inside
the photographic liquid windows, plus sample names and applicable interpretation
tags. The colored square swatches and hexadecimal labels were removed at the
user's request; calculated colors and separate metadata are unchanged.
The exact hex color is available in the closed-by-default Color details table
below the image. It follows the single sample or all samples currently shown.
All photographic pieces share one plot layer, avoiding hundreds of
independent annotation layers for large sample sets. The responsive desktop
layout reserves approximately 168 px for the lamp and 180 px per sample, giving
five columns at 1,100 px available width. The last row includes only real samples.

Lighting, transparency, and reflections in the scene are illustrative. They
do not change the computed hex color or the exported rendering metadata.

On 2026-09-12, the user requested an independent Dark/Light scene background.
Dark remains the original photograph and default. The built-in ImageGen tool
edited that exact reference to white/light-gray bench and rear laboratory
surfaces, retaining the same frame, texture, black lamp, clear glass, and liquid
window geometry. The result is `pasa-cuvette-photo-light.png`; a second ImageGen
edit removed the cuvette to create `pasa-cuvette-bench-light.png` for grids.
`pasa-cuvette-photo-light.rds` caches the light scene using the existing crop/mask
and requires no added runtime package. The `cuv_scene_background` radio changes
only the scene asset and label/caption contrast, independently of the app theme.
The chosen scene is used in single/grid image exports. Polygon coordinates,
alpha, calculated hexadecimal values, and Color details are unchanged.
Full prompts and render checks are in
`validation/gui_refresh_2026_09_11/light_scene/README.md`.

The photographic glass style and 15-sample, five-column layout were explicitly
approved by the user on 2026-09-11. The full refinement prompt and representative
review artifacts are archived in
`validation/gui_refresh_2026_09_11/photorealistic_candidate/README.md`.
