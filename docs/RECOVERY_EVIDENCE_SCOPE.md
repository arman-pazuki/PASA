# Recovery-evidence scope

The default Tested range search limit (K ≤ 4) refers to the reported scope of a separately distributed PASA synthetic recovery study. The original study design, raw fit records and analysis scripts are not part of this application package.

The source previously referred to a packaged analysis/deconvolution_evaluation/DECON_RECOVERY_DESIGN.tsv file. That locator was incorrect for this package. This note documents the limitation and does not replace the underlying evidence or independently validate its reported outcomes.

The K limit is a configurable software default, not a claim that a fitted component count identifies molecular species. Reproducibility or re-analysis of the study requires its separately distributed evidence records.
