# PASA releases

## 1.0.0

Initial public manuscript release with a fresh repository history.

- Dedicated input and analysis-settings pages, short and detailed tours, and anonymous Google Form feedback.
- Revised spectra and data-quality controls, sample-color scenes with light/dark backgrounds, and paginated metrics and cuvette displays.
- Verified fixes for text/workbook imports, literal-only session JSON, missing-value round trips, and delayed restoration of controls.
- Background file reading and feedback; cancellable deconvolution/bootstrap with guarded completion and explicit failure status.
- Bounded similarity work, reusable per-sample processing, supported-grid noise diagnostics, and clearer statistical interpretation.
- R 4.6.0 launchers, locked dependency restoration, source checksums, and platform test automation.

See RELEASE_VERIFICATION.md for the tests actually executed and their scope.
